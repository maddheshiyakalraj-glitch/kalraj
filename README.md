## About the Experiment
This experiment demonstrates the Field Oriented Control (FOC) or Vector Control system for a Permanent Magnet Synchronous Motor (PMSM). By decoupling the 3-phase currents into stator flux ($I_d$) and torque ($I_q$) components using Clarke and Park transformations, the AC motor can be controlled smoothly just like a separately excited DC motor.
